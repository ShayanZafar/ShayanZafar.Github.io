Your own visits

GoatCounter’s switch works per browser. Open the link below once in each browser you use, on each device, and confirm the message that appears.

Stop counting this browser

  • The link is a switch: opening it again, or reloading the page it opens, turns counting back on. The message confirms the new setting.
  • The setting is saved in this browser only. Private windows, other browsers and cleared browsing data are counted again.
  • On a network with a fixed IP address, you can also add that address in the dashboard under Settings → Tracking → Ignore IPs.

Tagged links for outreach

Add ?ref= and a short name to any page address. Visits through that link are listed under Referrers with that name.

  • https://shayanzafar.github.io/?ref=acme
  • https://shayanzafar.github.io/how-i-work/?ref=acme

To group several links, also add a campaign name, for example ?ref=acme&campaign=outreach. Campaigns have their own panel in the dashboard.
