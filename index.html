Side project · In active development Updated Oct 3, 2026

ThirteenF

Are more funds holding it, or fewer?

A data app that answers one question for every US-listed stock: are more funds holding it this quarter, or fewer? It loads the SEC’s Form 13F filings into a local database, ranks the whole market by the change, and lets you look up any stock or fund manager.

How it’s built

  • Python 3.12, DuckDB, FastAPI and Jinja2. Charts are SVG rendered on the server, with no front-end framework.
  • Raw SEC files are never edited, so every number can be rebuilt from source, and share totals must pass an implied-price check before they’re shown.
  • Built phase by phase from a written plan. Each phase ships only after its check passes, and tests compare results with published reference numbers.
  • Maps securities to tickers through the OpenFIGI API and stays within the SEC’s rate limits.
  • Developed with an AI pair programmer (Claude Code), guided by the project’s own design system and build plan.
